# 会走路的村庄

> 基于游客画像、真实点位与在地故事的 AI 乡村漫游 Agent

## 项目介绍

《会走路的村庄》是一个面向乡村文旅场景的 AI 实地叙事导览系统。系统根据游客身份、兴趣、时间等信息，自动生成一条个性化村庄漫游路线，并在每个点位生成专属故事、观察任务、拍照提示和互动问题。体验结束后，AI 会生成一份属于游客自己的村庄观察报告或古村故事卡片。

## 核心特性

- **个性化路线生成**：根据游客身份与兴趣，为每位游客生成不同的村庄漫游路线
- **动态点位故事**：同一个点位，不同身份的游客会看到不同的故事和任务
- **互动记录机制**：游客在每个点位可以记录感受和观察，形成个人体验数据
- **智能报告生成**：根据游客的路线和个人输入，AI 生成专属的观察报告和故事卡片

## 快速开始

### 环境要求

- Node.js >= 14
- Python >= 3.8
- 大模型 API（OpenAI、Claude 等）

### 安装依赖

```bash
# 前端依赖
cd frontend
npm install

# 后端依赖
cd backend
pip install -r requirements.txt
```

### 启动服务

```bash
# 启动前端
cd frontend
npm run dev

# 启动后端
cd backend
python main.py
```

访问 `http://localhost:3000` 即可开始体验。

## 核心功能

### 1. 游客身份测试

用户通过 3 个问题来确定游客身份：
- 你是谁？（角色选择）
- 你想体验什么？（兴趣选择）
- 你有多少时间？（时间选择）

系统生成对应的身份标签，如"乡野摄影猎人"、"老屋记忆采集员"等。

### 2. AI 生成个性化路线

系统预设 3 条主要路线，根据用户选择匹配合适的路线：
- **老屋认租线**：适合乡建研究者、城市白领
- **柿子与乡愁线**：适合亲子家庭、摄影爱好者
- **新村民创业线**：适合数字游民、青年创业者

### 3. 点位故事与任务生成

每个点位包含：
- 点位照片和真实介绍
- AI 生成的个性化故事
- 观察任务和拍照提示
- 采访问题

### 4. 游客输入与互动

游客在每个点位可输入一句话，记录观察和感受，这些内容会被保存并用于最终报告。

### 5. 最终报告生成

体验完成后，系统根据游客路线和个人输入，AI 生成：
- **深度版**：完整的田野观察报告
- **传播版**：适合分享的古村故事卡片

## 主要页面

1. **首页** - 项目介绍和开始按钮
2. **身份测试页** - 游客信息收集（角色、兴趣、时间）
3. **路线生成页** - 展示生成的身份和推荐路线
4. **点位体验页** - 显示点位故事、任务和用户输入框
5. **报告生成页** - 展示最终的观察报告或故事卡片

## API 接口

### 提交游客信息
```
POST /api/profile
```

### 获取点位内容
```
GET /api/spot/{spot_id}
```

### 保存用户输入
```
POST /api/note
```

### 生成最终报告
```
POST /api/report
```

详细接口文档见项目内的 API 文档。
